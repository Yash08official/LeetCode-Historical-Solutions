## Problem Description

We are given two arrays of positive integers `arr1` and `arr2`. A prefix of an integer is defined as an integer formed by one or more of its leading digits from left to right (for example, `12` is a prefix of `12345`, but `234` is not).

A common prefix between two numbers is a prefix shared by both. We need to find the length of the longest common prefix among all pairs `(x, y)` where `x` is in `arr1` and `y` is in `arr2`. If no pair shares a common prefix, return `0`.

---

## Examples

### Example 1

```text
Input: arr1 = [1,10,100], arr2 = [1000]
Output: 3
Explanation: There are 3 pairs (arr1[i], arr2[j]):
- The longest common prefix of (1, 1000) is 1.
- The longest common prefix of (10, 1000) is 10.
- The longest common prefix of (100, 1000) is 100.
The longest common prefix is 100 with a length of 3.
```

### Example 2

```text
Input: arr1 = [1,2,3], arr2 = [4,4,4]
Output: 0
Explanation: There exists no common prefix for any pair (arr1[i], arr2[j]), hence we return 0.
Note that common prefixes between elements of the same array do not count.
```

---

## Constraints

- `1 <= arr1.length, arr2.length <= 5 * 10^4`

- `1 <= arr1[i], arr2[i] <= 10^8`

---

## Problem Understanding

Key properties and scale:
- The sizes of `arr1` and `arr2` can be up to `5 * 10^4`.
- The integers can be up to `10^8`, meaning each integer has at most 8 or 9 decimal digits.
- Comparing all pairs `(x, y)` would require `5 * 10^4 * 5 * 10^4 = 2.5 * 10^9` comparisons, which will result in Time Limit Exceeded.
- Because an integer `<= 10^8` has at most 9 numerical prefixes (obtained by successively dividing by 10), precomputing and storing all prefixes of `arr1` in a hash set allows rapid lookup.

---

## Approach

### Brute Force Approach

Convert each number in `arr1` and `arr2` to a string, then for each pair `(x, y)` from `arr1 x arr2`, compute the common prefix character-by-character. This takes `O(n * m * D)` time, where `n = arr1.length`, `m = arr2.length`, and `D <= 9` is the number of digits, resulting in `O(n * m) = 2.5 * 10^9` operations and causing TLE.

### Optimized Approach

We use a `HashSet<Integer> s` to store all valid numerical prefixes of numbers in `arr1`.
- For every number `x` in `arr1`, we repeatedly insert `x` into `s` and update `x /= 10` until `x == 0`.
- For each number `x` in `arr2`, we check prefixes from longest to shortest (`x, x/10, x/100, ...`).
- The first prefix found in `s` is guaranteed to be the longest common prefix for that particular number `x`.
- We update `ans = max(ans, String.valueOf(x).length())` and immediately `break` to the next element of `arr2`.

### Step-by-Step Thinking Process

1. We want the maximum prefix length between any `x in arr1` and `y in arr2`.
2. Since each number has at most 9 prefixes, the total number of prefixes generated by `arr1` is at most `9 * 50,000 = 450,000`.
3. 450,000 integers can easily be stored in a `HashSet<Integer>`.
4. For each `y in arr2`, start checking `y` itself. If `y in s`, its full length is the answer for `y`. If not, check `y / 10`, `y / 100`, etc.
5. By checking `y` from longest to shortest, the first match found is the longest possible prefix for `y`, so we can record its length and break early.

### Algorithm / Intuition

The algorithm works via prefix hashing:
1. Instantiate `Set<Integer> s = new HashSet<>()`.
2. For each `x` in `arr1`:
   - While `x > 0`, add `x` to `s`, then `x /= 10`.
3. Initialize `ans = 0`.
4. For each `x` in `arr2`:
   - While `x > 0`:
     - If `s.contains(x)`, update `ans = Math.max(ans, String.valueOf(x).length())` and `break` (since subsequent prefixes will be strictly shorter).
     - Otherwise, `x /= 10`.
5. Return `ans`.

---

## Dry Run

Trace on Example 1: `arr1 = [1, 10, 100]`, `arr2 = [1000]`

- Insert prefixes of `arr1` into `s`:
  - `x = 1`: add `1`.
  - `x = 10`: add `10`, add `1`.
  - `x = 100`: add `100`, add `10`, add `1`.
  - `s = {1, 10, 100}`.
- Query prefixes of `arr2`:
  - `x = 1000`: `s.contains(1000)` is false -> `x /= 10 = 100`.
  - `x = 100`: `s.contains(100)` is true!
  - Length of `100` is 3. `ans = max(0, 3) = 3`.
  - Break inner loop.
- Return `ans = 3`, matching Example 1.

---

## Complexity Analysis

- **Time Complexity:** O((n + m) * log10(M)) — Where n = arr1.length, m = arr2.length, and M <= 10^8 is the maximum value. Each number has at most 9 decimal prefixes, requiring O(1) hash set operations per prefix.
- **Space Complexity:** O(n * log10(M)) — Storing all distinct prefixes of arr1 in the HashSet, which contains at most 9 * n integers.

## Key Learnings

- Generating numerical prefixes by repeatedly dividing by 10 (`x /= 10`) avoids string conversions.
- Testing prefixes in descending length order enables early breaking as soon as the first (longest) match is detected.
- Hash sets can effectively replace Tries when prefix depth is small (at most 9 digits).
