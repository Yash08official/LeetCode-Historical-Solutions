## Problem Description

You are given a **0-indexed** string `s` of even length `n` containing **exactly** `n / 2` opening square brackets `'['` and `n / 2` closing square brackets `']'`.

A bracket string is **balanced** if every opening `'['` can be matched with a corresponding closing `']'` to its right (formally: empty string, concatenation `AB` of balanced strings, or `[C]` around a balanced string `C`). In one operation, you may swap the characters at **any two indices** in `s`.

Return the **minimum number of swaps** needed to make `s` balanced.

---

## Examples

### Example 1

```text
Input: s = "][]["
Output: 1
Explanation: You can make the string balanced by swapping index 0 with index 3.
The resulting string is "[[]]".
```

### Example 2

```text
Input: s = "]]][[["
Output: 2
Explanation: You can do the following to make the string balanced:
- Swap index 0 with index 4. s = "[]][][".
- Swap index 1 with index 5. s = "[[][]]".
The resulting string is "[[][]]".
```

### Example 3

```text
Input: s = "[]"
Output: 0
Explanation: The string is already balanced.
```

---

## Constraints

- `n == s.length`

- `2 <= n <= 10^6`

- `n` is even.

- `s[i]` is either `'['`or `']'`.

- The number of opening brackets `'['` equals `n / 2`, and the number of closing brackets `']'` equals `n / 2`.

---

## Problem Understanding

- Because `s` has equal counts of `'['` and `']'`, making `s` balanced is **always possible**.
- Any already-matched `"[]"` pairs cancel out and never need to be touched. After cancelling all valid pairs, whatever unmatched brackets remain must all be closing brackets followed by an equal number of opening brackets: `]]]...[[[` (say `m` closing `']'` followed by `m` opening `'['`).
- Look at what **one greedy swap** achieves on `]]]...[[[`: swapping the leftmost unmatched `']'` with the rightmost unmatched `'['` turns `]]][[[` into `[]][[]`, which simultaneously cancels **two** pairs of brackets (`m` drops by `2`)! If only `m = 1` pair `][` remains, `1` swap turns it into `[]`.
- Therefore, if `m` unmatched closing brackets remain, the minimum number of swaps is `ceil(m / 2) = floor((m + 1) / 2)`!

---

## Approach

### Brute Force Approach

Modelling swaps as a shortest-path state search (BFS over strings generated by all `O(n^2)` index swaps) explores up to `C(n, n / 2)` distinct permutations—exponential in `n` and completely infeasible for `n <= 10^6`.

### Optimized Approach

Use an explicit `stack` array to cancel out every balanced `'['` + `']'` pair in a single left-to-right scan of `s`. Count the remaining unmatched closing brackets (`closedBrackets = stack.length / 2`) and return `Math.floor((closedBrackets + 1) / 2)`.

### Step-by-Step Thinking Process

1. Traverse `s` from left to right using `stack` to strip out all naturally balanced `[]` pairs.
2. Push every `'['` onto `stack` so it can match a future `']'`.
3. When encountering `']'`, check the top of `stack`: if `stack` is non-empty and its top is `'['`, pop `'['` because they form a valid balanced pair; otherwise push the unmatched `']'` onto `stack`.
4. At the end of the scan, `stack` holds `totalBrackets` unmatched characters, consisting of `closedBrackets = totalBrackets / 2` closing `']'`s followed by `closedBrackets` opening `'['`s.
5. Since each optimal swap resolves up to `2` unmatched `']'`s, return `Math.floor((closedBrackets + 1) / 2)`.

### Algorithm / Intuition

In `minSwaps`, `stack` acts as a bracket reducer. Every `'['` is pushed. Every `']'` either pops a waiting `'['` on top of `stack` or—if `stack` is empty or already ends with `']'`—gets pushed itself. Notice that once a `']'` is pushed, no `'['` can sit beneath a `']'` without having been popped earlier, so `stack` always maintains the invariant `']' * m + '[' * m` at completion! Dividing `stack.length` by `2` yields `closedBrackets = m`, and `Math.floor((closedBrackets + 1) / 2)` computes `ceil(m / 2)` using integer-safe math.

## Dry Run

Tracing Example 1: `s = "][]["`:

| `i` | `ch = s[i]` | Condition Triggered | `stack` After |
| :--- | :--- | :--- | :--- |
| `0` | `']'` | `stack.length === 0` -> push `']'` | `[']']` |
| `1` | `'['` | `ch === '['` -> push `'['` | `[']', '[']` |
| `2` | `']'` | Top of `stack` is `'['` -> `stack.pop()` | `[']']` |
| `3` | `'['` | `ch === '['` -> push `'['` | `[']', '[']` |

- End of loop: `totalBrackets = stack.length = 2`.
- `closedBrackets = 2 / 2 = 1`.
- `Math.floor((1 + 1) / 2) = Math.floor(1) = 1`. Returns `1`.

---

## Complexity Analysis

- **Time Complexity:** `O(n)` — We scan the `n` characters of `s` once, performing one `O(1)` `push` or `pop` on `stack` per character.
- **Space Complexity:** `O(n)` — In the worst case (e.g., `"]]]][[[["`), `stack` holds all `n` characters. (Note: space can be reduced to `O(1)` by tracking only the count of open `'['` brackets on the stack instead of storing characters explicitly).

## Key Learnings

- Cancelling already-valid pairs first reveals the minimal core structure of unmatched brackets (`]]]...[[[`), making the greedy insight (`1` swap fixes `2` mismatches) obvious.
- The integer formula `Math.floor((m + 1) / 2)` (or `(m + 1) >> 1`) cleanly computes `ceil(m / 2)` for non-negative integers `m`.
- Whenever a stack only ever needs to check whether `'['` is on top, its `O(n)` array can also be compressed into a single integer counter in `O(1)` space.
