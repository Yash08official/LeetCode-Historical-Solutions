## 📖 Repository Introduction

This repository transforms my historical archive of accepted LeetCode submissions into a rigorous, self-contained learning resource. Every solved problem resides in its own dedicated directory—grouped cleanly into numeric ranges of 100—and pairs the **exact accepted solution code** with an in-depth **`README.md`** walkthrough covering:

- **Verified Problem Metadata:** Official Problem ID, Difficulty, LeetCode link, and verified Topic Tags.
- **Clear Problem Formulation:** Original plain-English explanation of the problem rules, examples, constraints, and follow-up questions.
- **Structured DSA Mentorship:** Problem understanding, brute-force vs. optimized trade-offs, step-by-step thinking process, code-level intuition, concrete dry run, Big-O time/space complexity analysis, and transferable key learnings.

## 🧭 How to Navigate the Repository

1. **By Problem Number:** Open the corresponding 100-problem parent folder (for example, problem `0218` is inside [`201-300/0218 The Skyline Problem/`](./201-300/0218%20The%20Skyline%20Problem)) or use **[Part 1 of `INDEX.md`](./INDEX.md#part-1-index-by-problem-range)**.
2. **By DSA / SQL Topic:** Jump directly to **[Part 2 of `INDEX.md`](./INDEX.md#part-2-topic-wise-index-99-verified-leetcode-topics)** to practice curated problem sets across **99 verified topics** such as `Dynamic Programming`, `Graph`, `Binary Search`, `Two Pointers`, `Monotonic Stack`, `Trie`, or `Database`.
3. **For Revision & Interview Prep:** Inside any problem folder, read `README.md` first—try deriving the optimal solution from the **Problem Description**, **Constraints**, and **Step-by-Step Thinking Process**, trace through the **Dry Run**, and then inspect the linked source file.
4. **Quick Search in VS Code / GitHub:** Press `Ctrl+P` (VS Code) or `t` (GitHub) and type the 4-digit problem ID (e.g., `0146` or `3970`) to jump straight to its folder.
