## Problem Description

You are given a positive integer `n`.

Return the smallest number `x` greater than or equal to `n` such that the binary representation of `x` contains only set bits (all `1`s).

---

## Examples

### Example 1

**Input:** `n = 5`

**Output:** `7`

**Explanation:**

The binary representation of 7 is `"111"`.

### Example 2

**Input:** `n = 10`

**Output:** `15`

**Explanation:**

The binary representation of 15 is `"1111"`.

### Example 3

**Input:** `n = 3`

**Output:** `3`

**Explanation:**

The binary representation of 3 is `"11"`.

---

## Constraints

- `1 <= n <= 1000`

---

## Problem Understanding

- **Structure of Numbers with All Set Bits:** A number has all set bits if and only if its binary representation consists solely of ones: `1_2 = 1`, `11_2 = 3`, `111_2 = 7`, `1111_2 = 15`, `11111_2 = 31`, etc.
- **Mathematical Form:** These numbers are always of the form `2^k - 1` for some integer `k >= 1`.
- **Bitwise Progression:** Starting from `x = 1`, each subsequent all-ones number is generated by shifting left by 1 and adding 1: `x = (x << 1) + 1`.
- **Termination:** The first `x` generated that satisfies `x >= n` is guaranteed to be the smallest all-ones number greater than or equal to `n`.

---

## Approach

### Brute Force Approach

Check every integer `x = n, n + 1, n + 2, ...` sequentially: convert `x` to its binary string representation and check if every character is `'1'` (or verify `(x & (x + 1)) == 0`). While this works, jumping directly through all-ones numbers is much faster.

### Optimized Approach

We start with `let x = 1`. In a while loop with condition `x < n`, we update `x = (x << 1) + 1`, which shifts the current bits left by one and sets the least significant bit to 1. The moment `x >= n`, the loop terminates and we return `x`. With `n <= 1000`, the loop runs at most 10 times.

### Step-by-Step Thinking Process

1. Numbers whose binary representation contains only set bits are of the form `2^k - 1`.
2. The sequence of such numbers is 1, 3, 7, 15, 31, 63, 127, 255, 511, 1023, ...
3. Start with `x = 1`.
4. While `x < n`, shift left and add 1: `x = (x << 1) + 1`.
5. When `x >= n`, `x` is the smallest number with all set bits that is `>= n`.
6. Return `x`.

### Algorithm / Intuition

In `smallestNumber`: variable `x` is initialized to 1 (`0b1`). The condition `while (x < n)` tests if `x` is currently smaller than target `n`. In each iteration, `(x << 1) + 1` shifts the existing binary ones left and inserts a new `1` in the LSB, moving through all powers-of-two minus one (`1 -> 3 -> 7 -> 15 ...`). When the condition fails, `x` is the minimal all-ones value at least as large as `n`, and is returned directly.

## Dry Run

### Step-by-Step Execution on Example 1: `n = 5`

| Iteration | `x` (decimal) | `x` (binary) | `x < 5`? | Next `x = (x << 1) + 1` |
| :--- | :--- | :--- | :--- | :--- |
| Start | 1 | `"1"` | `1 < 5` (True) | `(1 << 1) + 1 = 3` (`"11"`) |
| 1 | 3 | `"11"` | `3 < 5` (True) | `(3 << 1) + 1 = 7` (`"111"`) |
| 2 | 7 | `"111"` | `7 < 5` (False) | Loop terminates |

Return `x = 7`.

---

## Complexity Analysis

- **Time Complexity:** `O(log n)` — The number of bits in `n` is `floor(log2(n)) + 1`. The while loop runs at most `log2(n)` times (at most 10 iterations for `n <= 1000`).
- **Space Complexity:** `O(1)` — Only a single variable `x` is used.

## Key Learnings

- Numbers with all bits set in binary correspond to Mersenne numbers `2^k - 1`.
- The operation `(x << 1) + 1` iteratively extends an all-ones bitmask by one bit in `O(1)` time.
